# Análise de Custos de Frete

## Sobre o projeto

Este projeto tem como objetivo analisar a composição dos custos de frete da Agrária, identificando os principais fatores que influenciam o valor do transporte de cargas.

A proposta é desenvolver uma ferramenta capaz de analisar os custos por rota e realizar simulações de diferentes cenários, considerando variáveis como combustível, distância, tipo de veículo, pedágios e legislação vigente.

## Objetivos

- Analisar os custos reais de transporte.
- Identificar diferenças de custos entre rotas.
- Avaliar os fatores que mais impactam o preço do frete.
- Desenvolver simulações de cenários.
- Transformar os dados em informações úteis para a tomada de decisão.

## Tecnologias utilizadas

- JavaScript
- Python
- Análise de dados
- Banco de dados

## Estrutura do projeto

A estrutura será organizada conforme o desenvolvimento das etapas:

- `dados/` – arquivos utilizados na análise.
- `src/` – códigos-fonte do projeto.
- `README.md` – documentação do projeto.
